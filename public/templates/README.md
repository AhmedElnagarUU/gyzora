# Bundled template imagery

Curated fallback imagery for the built-in templates, served from this repo so
the app is fully functional without any external service (DEC-006). These are
**illustrative sample images** — never labeled as a tenant's own work
(M-017 AC-05). Customer content (`isSampleContent` snapshots) is what the
public site renders once publishing lands (M-023).

## Source & license

All photos are from **Pexels** (free-to-use license — no attribution
required, free for commercial use). See https://www.pexels.com/license/
for the license text. Before shipping production imagery that relies on an
external provider, re-confirm the current usage terms (OD-3); these bundled
files intend to stay the offline default.
